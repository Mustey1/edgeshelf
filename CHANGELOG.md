# Changelog

All notable changes to Edge Shelf are documented in this file.

## 0.1.0

Initial public MVP:

- animated left-edge panel and global shortcut;
- Shelf with file, folder, screenshot, and drag-and-drop support;
- local clipboard history for text, links, images, and files;
- reusable snippets;
- Google Calendar through private iCal or read-only OAuth;
- tray controls and Windows startup support;
- self-contained portable build and per-user Windows installer.
